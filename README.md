# buzzkillington1201.github.io

A small GitHub Pages site. It currently holds the public home page and privacy policy for **Porch**, a private,
non-commercial home app used by one household, which Google requires before an app that uses its sign-in can leave
"Testing" mode.

| Page | Address |
|---|---|
| Porch home page | https://buzzkillington1201.github.io/porch/ |
| Porch privacy policy | https://buzzkillington1201.github.io/porch/privacy.html |

The pages are plain HTML with no scripts, trackers or external resources. GitHub Pages publishes the `main` branch
as it is pushed.
